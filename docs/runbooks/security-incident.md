# Runbook: Security incident

Response framework; contacts and legal workflow pending.

1. Notify security lead and preserve evidence.
2. Classify account compromise, data exposure, abuse or integrity compromise.
3. Contain affected credentials, sessions, keys or workloads through approved controls.
4. Preserve audit logs and forensic copies.
5. Assess data subjects, jurisdictions and notification duties with counsel.
6. Rotate secrets and restore trusted artifacts after root cause analysis.
7. Validate authorization, screening, custody and audit invariants before resuming.
8. Communicate through approved channels; document decisions and review.
