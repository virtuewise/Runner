# UX, UI & Accessibility

Status: Design baseline; detailed flows and token library pending. Owner: Product Design.

## Principles

Mission-first hierarchy: destination, status, next action and accountable party. Distinguish estimated from confirmed times. Explain eligibility without exposing sensitive risk signals. Confirm high-consequence actions. Poor connectivity must never imply custody confirmation. Disclose fees, payout and cancellation terms before acceptance.

## Core flows

Requester: create → screen → quote → publish → track → proof/dispute. Runner: verify → availability → offer → accept → pickup proof → travel → handover/delivery. Dispatcher: queue → candidates → assign → monitor → recover. Trust: alert → freeze → investigate → decide → notify → audit.

## Design system

Document color, typography, spacing, radius, elevation, motion and semantic states. Components need loading, empty, error, disabled, focus and high-contrast variants.

## Accessibility

Target WCAG 2.2 AA for web surfaces and platform accessibility guidance for native. Test screen-reader order/names, text scaling, keyboard navigation, contrast, non-color cues, reduced motion, touch targets and error recovery with real assistive technology.
